# lucky-draw

럭키 드로우 — 행사·모임용 경품 추첨 웹앱. 참가자와 경품을 등록하고, 원판을 돌려 당첨자를 뽑는다. React + Vite + TypeScript로 구현한 클라이언트 전용(로컬 저장) SPA.

## 주요 기능

- **참가자/경품 등록**: 텍스트영역에 실시간 입력(줄바꿈/쉼표 구분), 참가자는 "인원 수로 자동 생성"(1~N 번호) 지원. 경품은 같은 이름을 여러 줄 입력하면 수량으로 합산.
- **추첨 원판**: 남은 경품 수량만큼 슬롯 + 꽝 1칸으로 구성, 회전 애니메이션. 결과는 회전 시작 전 미리 확정하고 그 결과에 맞춰 원판이 멈춘다(먼저 돌리고 결과를 나중에 정하지 않음).
- **당첨 연출**: 당첨 시 화면 전체에 컨페티(폭죽) 효과.
- **진행 현황**: 남은 참가자/경품, 회차, 당첨자·꽝 명단 실시간 표시.
- **종료 처리**: 모든 경품 소진 또는 추첨 대상 소진 시 자동 종료, 당첨자 명단 CSV 내보내기, 행사 초기화(확인 후 실행).
- **새로고침 복원**: 진행 중 데이터는 브라우저 저장소에 자동 저장. 회전 중 새로고침해도 안전하게 정리됨.

## 개발

```bash
npm install
npm run dev     # 개발 서버
npm run build   # 타입체크 + 프로덕션 빌드
npm run test    # 유닛 테스트 (추첨 확률 로직)
```
